# FREE pt/nl MEANINGS (from LOD — no translation needed)

These are the Portuguese + Dutch word/verb MEANINGS, pulled straight from the LOD source
(professional translations, same source as the existing en/fr/de). No API was spent on these.

- `dict_meanings_ptnl.json` — `{ "<headword>\u0001<ipa>": {"l","i","senses":[{"pt","nl","pt_clar","nl_clar"}, ...]} }`
  one sense entry per dictionary sense, in order. pt on 34,280 senses, nl on 33,332 (rest have none in LOD).
- `verb_meanings_ptnl.json` — `{ "<verb>": {"pt","nl","pt_all":[...],"nl_all":[...]} }`
  all 3,658 verbs; only 3 lack pt, 70 lack nl in LOD.

Inject these into the master alongside en/fr/de. Examples (pt/nl) come from the translate job.
